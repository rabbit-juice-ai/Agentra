每个页面都按同一骨架出图：导航区、页面头、主工作区、详情栏、状态栏。按钮位置在页面之间不漂移。

2·3·4页面头固定三段式

左：标题 + 一句说明（数量、状态）。中：搜索与筛选，永远在主按钮左边。右：次要操作 → 主操作。主操作固定在右上角，位置不随页面内容变化。

4一个视图只有一个实色主按钮

主按钮 = 当前页面最想让你做的事：新建 Work、发起运行、发布、通过。其他操作一律描边或幽灵样式，不与主按钮抢视觉。

5·6列表与详情分开，比例固定

列表-详情：380 / 1fr（审批 400 / 1fr，运行 320 / 1fr）。列表只负责定位，详情承担阅读和操作；详情底部固定决策栏，滚动时不丢按钮。

!破坏性操作离开主操作区

终止、删除、恢复、驳回：列表行进 … 菜单；详情页放页脚 Danger Zone；审批驳回放在决策栏最左，与“通过”拉开距离。永远不做成实色红按钮。

A多 Agent：按状态排，按 Provider 筛

Agent 列表默认按“执行中 → 可用 → 空闲”排序；Provider 只做筛选 chips，不把列表拆成多组。执行者用 15px 中性徽标（CC / CX / GM）标识，徽标不参与排序，也不使用第二个强调色。

固定在标题与主按钮之间，宽度 232px。切换视图（看板/列表）紧贴筛选右侧。

4操作区

从右到左：主按钮 → 次按钮 → 图标按钮。主按钮永远在最右，且一屏只有一个。

5主工作区

看板铺满；表单/阅读页限制 1152px；详情页与右侧栏按固定比例分栏，不随窗口拉长。

6详情/属性栏

只放当前选中项的属性、预览和局部操作。全局操作留在页面头，不重复。
